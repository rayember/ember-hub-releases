# Ember Hub releases

Downloads for Ember Hub — the desktop app for installing and updating Ray Ember's
Godot plugins, generators and demos.

Builds for Windows, macOS and Linux are on the [Releases](../../releases) page.

There is no source code in here. This repository only carries the download files,
because release attachments give the stable public URLs the in-app updater needs.

The builds are not code-signed yet, so Windows and macOS will warn the first time
you open one. https://hub.rayember.com explains how to get past that on each
platform, and lists what Ember Hub actually does.

Ember Hub is always optional — every Ray Ember product can still be downloaded
and installed by hand without it.
